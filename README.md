# Splot — Portafolio

Versión ligera del portafolio, con imágenes WebP comprimidas y efecto 3D.

## Publicar en GitHub y Vercel

1. Crea un repositorio en GitHub.
2. Sube el contenido de esta carpeta: `index.html`, los archivos CSS y JavaScript y la carpeta `img`. `index.html` debe quedar en la raíz del repositorio.
3. En Vercel, importa el repositorio. Selecciona **Other** como framework, sin comando de compilación y con la carpeta raíz como directorio de publicación.
4. Publica el proyecto y conecta tu dominio desde **Settings → Domains**.

Para GitHub Pages: en **Settings → Pages**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.

Abre `index.html` para revisar el portafolio en tu computadora.
